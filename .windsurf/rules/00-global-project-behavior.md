# Global Project Behavior Rules

- Do not claim DONE without actual proof.
- Do not hide failures.
- Do not call failures pre-existing without baseline proof.
- Prefer small surgical changes.
- Do not silently fallback.
- Do not paste huge files unless asked.
- Return implementation reports with:
  - Status
  - Files modified
  - Root cause
  - Commands run
  - Test results
  - Artifact proof
  - Risks
  - Explicit confirmation
